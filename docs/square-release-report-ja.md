# 西天満つきや｜Square画面内決済 実装・検証報告

2026年10月26日。実装は別ブランチ・PR #15に保存し、HTTPS Sandboxへ反映済み。本番main、既存予約、Square本番設定、公式サイト公開版は変更していません。

1. **実装可否：可能。** 日本語・英語の予約画面内にSquareカード入力を組み込み、Sandboxで決済→予約確定まで確認しました。3Dセキュア認証画面も同ページ内で表示できました。実際の発行会社によっては銀行アプリ等の本人認証が必要です。
2. **再利用と追加開発：** 空席・予約・顧客・監査・確定通知・朝倉承認付き返金を再利用。15分の席確保、支払いセッション、同じキーでの再照合、SDK入力、管理画面状態表示を追加。電話請求書/SMS、日本語銀行振込、英語カード限定、VIP既存特例を維持。公式サイト4ページ、予約画面・確認メール・英語コンシェルジュ・スタッフFAQ・管理案内を更新しました。公式サイト変更は版47に保存し公開待ちです。
3. **費用：** Square公式の現行標準eコマースAPI料率は3.6%。66,000円あたり2,376円、2名132,000円で4,752円です。標準請求書料率3.25%との差は1名あたり231円。個別契約料率がある場合は契約を優先。SDK追加ライセンス費なし、今回のSandboxはRender無料枠で有料プラン変更なし。出典：https://squareup.com/jp/ja/payments/our-fees （2026-10-26確認）。
4. **事故防止：** 共通在庫のDBトランザクションで重複席確保を防止。固定の決済・注文キー、決済IDの一意制約、サーバー金額計算、Square APIの金額/店舗/注文/通貨照合、署名Webhookで二重課金・改ざんを防止。通信不明時は席を保持して照合、明確な拒否・期限切れは席を解放します。
5. **検証：** 新規自動テスト24件、FAQ8件成功。実Sandboxで日本語3DS成功、英語成功・拒否・郵便番号・認証中止・再読込みを確認。実Webhookは200、132,000円のテスト返金はSquare APIでCOMPLETED確認。従来テストにはmainでも再現する既存19件の失敗/エラーがあり、新規の従来機能退行は確認されませんでした。iPhone/Safari実機、ブラウザ通信断/再起動の実機結合、実通知配送は未確認です。
6. **公開前の作業・承認対象：** iPhone/Safariの実機確認、SQLite整合バックアップ、本番既存Webhookにpayment.created/payment.updated追加（既存3イベント維持）、本番Application ID・暗号鍵・有効化設定追加、PR #15マージとRender本番反映、公式サイト版47の同時公開。初回指示の本番公開・本番設定変更の承認範囲を確定してから反映します。実カード課金テストは実施しません。
